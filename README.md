# Начало работы с Create React App

Этот проект был создан с помощью [Create React App](https://github.com/facebook/create-react-app).

## Доступные скрипты

В каталоге проекта вы можете выполнить:

### `npm start`

Запускает приложение в режиме разработки.\
Откройте [http://localhost:3000](http://localhost:3000) в браузере, чтобы посмотреть приложение.

Страница будет автоматически перезагружаться при изменениях в коде.\
Также вы можете увидеть ошибки линтинга в консоли.

### `npm test`

Запускает тестовый раннер в интерактивном режиме просмотра.\
Подробнее см. раздел о [запуске тестов](https://facebook.github.io/create-react-app/docs/running-tests).

### `npm run build`

Создаёт production-сборку приложения в папке `build`.\
React корректно упаковывается в production-режиме, а сборка оптимизируется для наилучшей производительности.

Сборка минифицируется, а имена файлов содержат хэши.\
Ваше приложение готово к деплою!

Подробнее см. раздел о [деплое](https://facebook.github.io/create-react-app/docs/deployment).

### `npm run eject`

**Внимание: это необратимая операция. После `eject` вернуться назад нельзя!**

Если вас не устраивают инструменты сборки и выбранные конфигурации, вы можете выполнить `eject` в любой момент. Эта команда удалит единственную зависимость-сборщик из вашего проекта.

Вместо этого все конфигурационные файлы и транзитивные зависимости (webpack, Babel, ESLint и т. д.) будут скопированы прямо в ваш проект, чтобы вы получили полный контроль над ними. Все команды, кроме `eject`, продолжат работать, но будут ссылаться на скопированные скрипты, чтобы вы могли их настраивать. На этом этапе вы действуете на свой страх и риск.

Вам не обязательно когда-либо использовать `eject`. Подобранный набор возможностей подходит для небольших и средних проектов, и вы не должны чувствовать себя обязанными применять эту функцию. Однако мы понимаем, что этот инструмент был бы бесполезен, если бы вы не могли его настроить, когда будете к этому готовы.
