# Create React App ile Başlangıç

Bu proje [Create React App](https://github.com/facebook/create-react-app) ile başlatıldı.

## Kullanılabilir Komutlar

Proje dizininde aşağıdaki komutları çalıştırabilirsiniz:

### `npm start`

Uygulamayı geliştirme modunda çalıştırır.\
Tarayıcınızda görüntülemek için [http://localhost:3000](http://localhost:3000) adresini açın.

Sayfa, değişiklik yaptığınızda otomatik olarak yeniden yüklenir.\
Ayrıca konsolda herhangi bir lint hatasını da görebilirsiniz.

### `npm test`

Test çalıştırıcısını etkileşimli izleme modunda başlatır.\
Daha fazla bilgi için [testlerin çalıştırılması](https://facebook.github.io/create-react-app/docs/running-tests) bölümüne bakın.

### `npm run build`

Uygulamayı üretim için `build` klasörüne derler.\
React’i üretim modunda doğru şekilde paketler ve en iyi performans için yapıyı optimize eder.

Yapı küçültülür (minify edilir) ve dosya adları hash içerir.\
Uygulamanız dağıtıma hazır!

Daha fazla bilgi için [dağıtım](https://facebook.github.io/create-react-app/docs/deployment) bölümüne bakın.

### `npm run eject`

**Not: Bu tek yönlü bir işlemdir. `eject` ettikten sonra geri dönemezsiniz!**

Derleme aracı ve yapılandırma seçimlerinden memnun değilseniz, istediğiniz zaman `eject` edebilirsiniz. Bu komut, projeden tekil bağımlılığı kaldırır.

Bunun yerine tüm yapılandırma dosyalarını ve dolaylı bağımlılıkları (webpack, Babel, ESLint, vb.) projenizin içine kopyalar; böylece bunlar üzerinde tam kontrole sahip olursunuz. `eject` dışındaki tüm komutlar çalışmaya devam eder, ancak kopyalanan betiklere işaret eder; böylece istediğiniz değişiklikleri yapabilirsiniz. Bu noktadan sonra sorumluluk tamamen size aittir.

`eject` komutunu asla kullanmak zorunda değilsiniz. Seçilmiş özellik seti küçük ve orta ölçekli dağıtımlar için yeterlidir ve bu özelliği kullanma zorunluluğu hissetmemelisiniz. Ancak, bu aracı yalnızca hazır olduğunuzda özelleştirebilmenizin önemli olduğunu anlıyoruz.
