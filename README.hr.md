# Početak rada s Create React App

Ovaj je projekt inicijaliziran pomoću [Create React App](https://github.com/facebook/create-react-app).

## Dostupne skripte

U direktoriju projekta možete pokrenuti:

### `npm start`

Pokreće aplikaciju u razvojnom načinu.
Otvorite [http://localhost:3000](http://localhost:3000) kako biste je vidjeli u svom pregledniku.

Stranica će se ponovno učitati kada napravite promjene.
Također možete vidjeti sve greške lintera u konzoli.

### `npm test`

Pokreće testni pokretač u interaktivnom načinu nadziranja.
Pogledajte odjeljak o [pokretanju testova](https://facebook.github.io/create-react-app/docs/running-tests) za više informacija.

### `npm run build`

Izrađuje aplikaciju za produkciju u mapu `build`.
Ispravno spaja React u produkcijskom načinu i optimizira gradnju za najbolje performanse.

Gradnja je minificirana, a nazivi datoteka uključuju hash-eve.
Vaša je aplikacija spremna za implementaciju!

Pogledajte odjeljak o [implementaciji](https://facebook.github.io/create-react-app/docs/deployment) za više informacija.

### `npm run eject`

Napomena: ovo je jednosmjerna operacija. Nakon što izvršite `eject`, nema povratka!

Ako niste zadovoljni odabirom alata i konfiguracijom gradnje, možete u bilo kojem trenutku pokrenuti `eject`. Ova naredba uklonit će jedinu ovisnost o alatu za gradnju iz vašeg projekta.

Umjesto toga, kopirat će sve konfiguracijske datoteke i tranzitivne ovisnosti (webpack, Babel, ESLint itd.) izravno u vaš projekt kako biste imali potpunu kontrolu nad njima. Sve naredbe osim `eject` i dalje će raditi, ali će pokazivati na kopirane skripte kako biste ih mogli prilagoditi. U tom ste trenutku prepušteni sami sebi.

Ne morate nikada koristiti `eject`. Kurirani skup značajki prikladan je za male i srednje implementacije i ne biste se trebali osjećati obveznima koristiti ovu značajku. Međutim, razumijemo da ovaj alat ne bi bio koristan ako ga ne biste mogli prilagoditi kada budete spremni.
