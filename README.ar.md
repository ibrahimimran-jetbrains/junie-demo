# البدء باستخدام Create React App

تم إنشاء هذا المشروع باستخدام [Create React App](https://github.com/facebook/create-react-app).

## الأوامر المتاحة

في مجلد المشروع يمكنك تشغيل:

### `npm start`

يشغّل التطبيق في وضع التطوير.
افتح الرابط [http://localhost:3000](http://localhost:3000) لعرضه في المتصفح.

ستُعاد عملية التحميل تلقائيًا عند إجراء تغييرات،
وقد ترى كذلك أي أخطاء lint في وحدة التحكم (Console).

### `npm test`

يشغّل أداة الاختبارات في وضع المراقبة التفاعلي.
للمزيد من المعلومات، راجع قسم [تشغيل الاختبارات](https://facebook.github.io/create-react-app/docs/running-tests).

### `npm run build`

ينشئ نسخة الإنتاج من التطبيق داخل مجلد `build`.
يقوم بربط React في وضع الإنتاج ويُحسّن البناء لأفضل أداء.

ستكون الحزمة مصغّرة (minified) وأسماء الملفات ستتضمّن بصمات (hashes).
تطبيقك جاهز للنشر!

راجع قسم [النشر](https://facebook.github.io/create-react-app/docs/deployment) لمزيد من المعلومات.

### `npm run eject`

ملاحظة مهمة: هذه عملية باتجاه واحد. بعد تنفيذ `eject` لا يمكنك التراجع!

إذا لم تكن راضيًا عن أداة البناء وخيارات الإعدادات، يمكنك تنفيذ `eject` في أي وقت. سيزيل هذا الأمر الاعتماد الأحادي على الحزمة من مشروعك.

بدلاً من ذلك، سيقوم بنسخ ملفات الإعدادات وكافة الاعتمادات الانتقالية (مثل webpack وBabel وESLint وغيرها) مباشرةً إلى مشروعك، لتصبح لديك السيطرة الكاملة عليها. ستستمر جميع الأوامر بالعمل باستثناء `eject`، لكنها ستشير إلى السكربتات المنسوخة بحيث يمكنك تعديلها. في هذه المرحلة ستكون مسؤولًا عن إدارتها بنفسك.

لا تحتاج إلى استخدام `eject` إطلاقًا. مجموعة الميزات المنسّقة مناسبة للنشرّات الصغيرة والمتوسطة، ولا ينبغي أن تشعر بأنك مُلزَم باستخدام هذه الميزة. ومع ذلك، نحن نتفهم أن هذه الأداة لن تكون مفيدة إذا لم يكن بوسعك تخصيصها عندما تكون جاهزًا لذلك.
