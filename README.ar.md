# البدء مع Create React App

تم إنشاء هذا المشروع باستخدام [Create React App](https://github.com/facebook/create-react-app).

## الأوامر المتاحة

في مجلد المشروع، يمكنك تشغيل:

### `npm start`

يشغّل التطبيق في وضع التطوير.
افتح الرابط [http://localhost:3000](http://localhost:3000) لعرضه في المتصفح.

سيُعاد تحميل الصفحة عند إجراء تغييرات.
قد ترى أيضًا أي أخطاء في الفحص (lint) داخل وحدة التحكم.

### `npm test`

يشغّل أداة الاختبار في وضع المراقبة التفاعلي.
راجع قسم [تشغيل الاختبارات](https://facebook.github.io/create-react-app/docs/running-tests) لمزيد من المعلومات.

### `npm run build`

يبني التطبيق لبيئة الإنتاج داخل مجلد `build`.
يقوم بربط React بوضع الإنتاج ويعمل على تحسين الحزمة لأفضل أداء.

يتم تصغير (minify) الناتج وتتضمن أسماء الملفات بصمات (hashes).
تطبيقك جاهز للنشر!

راجع قسم [النشر](https://facebook.github.io/create-react-app/docs/deployment) لمزيد من المعلومات.

### `npm run eject`

ملاحظة مهمة: هذه عملية باتجاه واحد. بمجرد تنفيذ `eject` لن تتمكن من التراجع!

إذا لم تكن راضيًا عن أداة البناء وخيارات الضبط، يمكنك في أي وقت تنفيذ `eject`. هذا الأمر سيزيل الاعتماد الواحد من مشروعك.

بدلاً من ذلك، سيقوم بنسخ جميع ملفات الإعدادات والاعتمادات العابرة (مثل webpack وBabel وESLint وغيرها) مباشرة إلى مشروعك لتملك تحكمًا كاملاً بها. ستظل جميع الأوامر الأخرى باستثناء `eject` تعمل، لكنها ستشير إلى السكربتات المنسوخة بحيث يمكنك تعديلها. عند هذه النقطة ستكون مسؤولًا بالكامل عن الإعداد.

لا يتوجب عليك استخدام `eject` إطلاقًا. مجموعة الميزات المنسقة مناسبة للنشرّات الصغيرة والمتوسطة، ولا ينبغي أن تشعر بأنك مُلزَم باستخدام هذه الميزة. ومع ذلك، نفهم أن هذه الأداة لن تكون مفيدة إن لم يكن بإمكانك تخصيصها عندما تكون جاهزًا لذلك.
