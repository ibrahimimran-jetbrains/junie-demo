# البدء باستخدام Create React App

تم إنشاء هذا المشروع باستخدام [Create React App](https://github.com/facebook/create-react-app).

## الأوامر المتاحة

في مجلد المشروع، يمكنك تشغيل:

### `npm start`

يشغّل التطبيق في وضع التطوير.
افتح [http://localhost:3000](http://localhost:3000) لعرضه في المتصفح.

ستُعاد تحميل الصفحة عند إجراء تغييرات.
قد ترى أيضًا أي أخطاء Lint في وحدة التحكم (Console).

### `npm test`

يشغّل أداة الاختبار في وضع المراقبة التفاعلي.
راجع قسم [تشغيل الاختبارات](https://facebook.github.io/create-react-app/docs/running-tests) لمزيد من المعلومات.

### `npm run build`

يبني التطبيق للإنتاج في مجلد `build`.
يقوم بدمج React في وضع الإنتاج وتحسين الحزمة لأفضل أداء.

تكون الحزمة مصغّرة (minified) وتتضمّن أسماء الملفات القيم التجزئية (hashes).
تطبيقك جاهز للنشر!

راجع قسم [النشر](https://facebook.github.io/create-react-app/docs/deployment) لمزيد من المعلومات.

### `npm run eject`

ملاحظة: هذه عملية باتجاه واحد. بمجرد تنفيذ `eject` لا يمكنك التراجع!

إذا لم تكن راضيًا عن أداة البناء وخيارات الإعداد، يمكنك تنفيذ `eject` في أي وقت. سيؤدي هذا الأمر إلى إزالة تبعية البناء المفردة من مشروعك.

بدلاً من ذلك، سيقوم بنسخ جميع ملفات الإعداد والاعتمادات الانتقالية (webpack وBabel وESLint وغيرها) مباشرةً إلى مشروعك بحيث تحصل على تحكم كامل بها. ستستمر جميع الأوامر باستثناء `eject` بالعمل، لكنها ستشير إلى السكربتات المنسوخة بحيث يمكنك تعديلها. عند هذه النقطة ستكون المسؤول بالكامل.

لا يتوجب عليك أبدًا استخدام `eject`. مجموعة الميزات المنسّقة مناسبة للنشرّات الصغيرة والمتوسطة، ولا ينبغي أن تشعر بأنك مُلزم باستخدام هذه الميزة. ومع ذلك، نفهم أن هذه الأداة لن تكون مفيدة إذا لم تتمكن من تخصيصها عندما تكون جاهزًا لذلك.
