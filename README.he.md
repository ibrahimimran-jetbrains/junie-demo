# תחילת עבודה עם Create React App

הפרויקט הזה נוצר באמצעות [Create React App](https://github.com/facebook/create-react-app).

## סקריפטים זמינים

בתיקיית הפרויקט, ניתן להריץ:

### `npm start`

מריץ את האפליקציה במצב פיתוח.\
פתחו את [http://localhost:3000](http://localhost:3000) כדי לצפות בה בדפדפן.

העמוד ירענן את עצמו כאשר תבצעו שינויי קוד.\
ייתכן שתראו גם שגיאות Lint במסוף.

### `npm test`

מפעיל את רצת הבדיקות במצב אינטראקטיבי וצופה.\
ראו את הסעיף על [הרצת בדיקות](https://facebook.github.io/create-react-app/docs/running-tests) למידע נוסף.

### `npm run build`

יוצר Build להפקה בתיקיית `build`.\
הפקודה אורזת כראוי את React במצב Production ומבצעת אופטימיזציות לביצועים מיטביים.

הקוד המהודק מינימלי ושמות הקבצים כוללים Hashes.\
האפליקציה שלכם מוכנה לפריסה!

ראו את הסעיף על [פריסה](https://facebook.github.io/create-react-app/docs/deployment) למידע נוסף.

### `npm run eject`

הערה: זו פעולה חד-כיוונית. לאחר שתבצעו `eject`, לא ניתן לחזור אחורה!

אם אינכם מרוצים מבחירות כלי הבנייה והקונפיגורציה, ניתן לבצע `eject` בכל זמן. פקודה זו תסיר את התלות הבודדת בפרויקט.

במקום זאת, היא תעתיק את כל קבצי התצורה ואת התלויות הטרנזיטיביות (webpack, Babel, ESLint וכו') ישירות לפרויקט כך שתהיה לכם שליטה מלאה בהם. כל הפקודות מלבד `eject` ימשיכו לעבוד, אך הן יצביעו על הסקריפטים המועתקים כך שתוכלו להתאים אותם. בשלב זה האחריות עליכם.

אין חובה להשתמש ב-`eject` אי פעם. סט התכונות המובנה מתאים לפריסות קטנות ובינוניות, ואין צורך להרגיש מחויבים להשתמש בתכונה הזו. עם זאת, אנו מבינים שכלי זה לא היה שימושי אם לא יכולתם להתאים אותו כאשר תהיו מוכנים לכך.
