# Create React App के साथ शुरुआत करना

यह प्रोजेक्ट [Create React App](https://github.com/facebook/create-react-app) के साथ बूटस्ट्रैप किया गया है।

## उपलब्ध स्क्रिप्ट्स

प्रोजेक्ट डायरेक्टरी में, आप निम्न कमांड चला सकते हैं:

### `npm start`

यह ऐप को डेवलपमेंट मोड में चलाता है।\
अपने ब्राउज़र में देखने के लिए [http://localhost:3000](http://localhost:3000) खोलें।

जब आप बदलाव करेंगे तो पेज अपने आप रीलोड हो जाएगा।\
आप कंसोल में किसी भी लिंट त्रुटि को भी देख सकते हैं।

### `npm test`

यह इंटरएक्टिव वॉच मोड में टेस्ट रनर को लॉन्च करता है।\
अधिक जानकारी के लिए [टेस्ट चलाना](https://facebook.github.io/create-react-app/docs/running-tests) अनुभाग देखें।

### `npm run build`

यह प्रोडक्शन के लिए ऐप को `build` फ़ोल्डर में बनाता है।\
यह प्रोडक्शन मोड में React को सही ढंग से बंडल करता है और सर्वोत्तम प्रदर्शन के लिए बिल्ड को ऑप्टिमाइज़ करता है।

बिल्ड मिनिफाइड होता है और फ़ाइल नामों में हैश शामिल होते हैं।\
आपका ऐप डिप्लॉय करने के लिए तैयार है!

और जानकारी के लिए [डिप्लॉयमेंट](https://facebook.github.io/create-react-app/docs/deployment) अनुभाग देखें।

### `npm run eject`

ध्यान दें: यह एकतरफ़ा प्रक्रिया है। एक बार आप `eject` कर दें, तो वापस नहीं जा सकते!

यदि आप बिल्ड टूल और कॉन्फ़िगरेशन विकल्पों से संतुष्ट नहीं हैं, तो आप कभी भी `eject` चला सकते हैं। यह कमांड आपके प्रोजेक्ट से सिंगल बिल्ड डिपेंडेंसी को हटा देगा।

इसके बजाय, यह सभी कॉन्फ़िगरेशन फ़ाइलें और ट्रांज़िटिव डिपेंडेंसी (webpack, Babel, ESLint, आदि) सीधे आपके प्रोजेक्ट में कॉपी कर देगा ताकि आपको उन पर पूरा नियंत्रण मिल सके। `eject` को छोड़कर बाकी सभी कमांड काम करती रहेंगी, लेकिन वे कॉपी की गई स्क्रिप्ट्स की ओर संकेत करेंगी ताकि आप उन्हें ट्वीक कर सकें। इस बिंदु पर आप स्वयं ज़िम्मेदार होंगे।

आपको कभी भी `eject` का उपयोग करने की आवश्यकता नहीं है। क्यूरेटेड फीचर सेट छोटे और मध्यम डिप्लॉयमेंट के लिए उपयुक्त है, और आपको इस फीचर का उपयोग करने के लिए बाध्य महसूस नहीं करना चाहिए। हालांकि हम समझते हैं कि यदि आप तैयार हों तो इस टूल को कस्टमाइज़ करने में सक्षम होना उपयोगी होगा।
