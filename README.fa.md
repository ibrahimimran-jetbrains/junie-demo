# شروع کار با Create React App

این پروژه با استفاده از [Create React App](https://github.com/facebook/create-react-app) راه‌اندازی شده است.

در دسترس به زبان‌ها: [English](./README.md) | فارسی

## اسکریپت‌های قابل استفاده

در پوشهٔ پروژه می‌توانید دستورهای زیر را اجرا کنید:

### `npm start`

برنامه را در حالت توسعه اجرا می‌کند.\
برای مشاهده در مرورگر، به آدرس [http://localhost:3000](http://localhost:3000) بروید.

با اعمال تغییرات، صفحه به‌طور خودکار ریلود می‌شود.\
همچنین ممکن است خطاهای لینت را در کنسول ببینید.

### `npm test`

رانر تست را در حالت تماشای تعاملی اجرا می‌کند.\
برای اطلاعات بیشتر بخش [اجرای تست‌ها](https://facebook.github.io/create-react-app/docs/running-tests) را ببینید.

### `npm run build`

نسخهٔ تولید (Production) برنامه را در پوشهٔ `build` می‌سازد.\
ری‌اکت را در حالت تولید به‌درستی باندل می‌کند و ساخت را برای بهترین کارایی بهینه می‌سازد.

خروجی کوچک‌سازی (minify) می‌شود و نام فایل‌ها شامل هش هستند.\
برنامهٔ شما آمادهٔ استقرار است!

برای اطلاعات بیشتر بخش [استقرار](https://facebook.github.io/create-react-app/docs/deployment) را ببینید.

### `npm run eject`

توجه: این عملیات یک‌طرفه است. پس از `eject` امکان بازگشت وجود ندارد!

اگر از ابزار ساخت و انتخاب‌های پیکربندی راضی نیستید، هر زمان می‌توانید `eject` کنید. این دستور وابستگی ساختِ واحد را از پروژه حذف می‌کند.

در عوض، تمام فایل‌های پیکربندی و وابستگی‌های انتقالی (webpack، Babel، ESLint و غیره) را مستقیماً داخل پروژهٔ شما کپی می‌کند تا کنترل کامل داشته باشید. همهٔ دستورات به‌جز `eject` همچنان کار می‌کنند، اما به اسکریپت‌های کپی‌شده اشاره خواهند کرد تا بتوانید آن‌ها را تغییر دهید. از این نقطه به بعد مسئولیت با خودتان است.

هرگز مجبور نیستید از `eject` استفاده کنید. مجموعهٔ قابلیت‌های انتخاب‌شده برای استقرارهای کوچک و متوسط مناسب است و نباید احساس کنید مجبور به استفاده از این ویژگی هستید. بااین‌حال می‌دانیم این ابزار بدون امکان شخصی‌سازی در زمانی که آماده‌اید چندان مفید نخواهد بود.
