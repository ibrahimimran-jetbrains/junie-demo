# البداية ويّه Create React App

هذا المشروع متكوّن باستخدام [Create React App](https://github.com/facebook/create-react-app).

## الأوامر المتوفّرة

بداخل مجلّد المشروع تگدر تشغّل:

### `npm start`

يشغّل التطبيق بوضع التطوير.
افتح [http://localhost:3000](http://localhost:3000) حتى تشوفه بالمتصفح.

الصفحة راح تعيد التحميل أوتوماتيكياً من تغيّر أي شي.
وممكن يطلع لك أخطاء lint بالكونسول إذا موجودة.

### `npm test`

يشغّل مشغّل الاختبارات بوضع تفاعلي يراقب التغييرات.
شوف قسم [تشغيل الاختبارات](https://facebook.github.io/create-react-app/docs/running-tests) لمعلومات أكثر.

### `npm run build`

يسوّي بناء للإنتاج داخل مجلّد `build`.
يجمع React بوضع الإنتاج ويعدّل الأداء حتى تحصل أفضل نتائج.

حجم الملفات يصير أصغر وأسماء الملفات بيها hashes.
تطبيقك صار جاهز للنشر!

شوف قسم [النشر](https://facebook.github.io/create-react-app/docs/deployment) لمعلومات أكثر.

### `npm run eject`

ملاحظة مهمّة: هذي خطوة باتجاه واحد. إذا سويت `eject` ما تگدر ترجع!

إذا ما عاجبك إعدادات أداة البناء والكونفيگ الافتراضي، تگدر بأي وقت تسوي `eject`.
هذي التعليمة تشيل الاعتماد الواحد من مشروعك.

بداله، راح تنسخ كل ملفات الإعدادات والاعتمادات الثانوية (webpack, Babel, ESLint, إلخ) داخل مشروعك حتى يصير عندك تحكّم كامل بيها.
كل الأوامر غير `eject` تبقى تشتغل، بس راح تشير للسكربتات المنسوخة حتى تگدر تعدّلها. بهالمرحلة تصير المسؤول الوحيد عنها.

مو ضروري تستخدم `eject` أبدًا. المزايا الجاهزة مناسبة للمشاريع الصغيرة والمتوسّطة، ومفروض ما تحس إنك مجبور تستخدمها. بس نفهم إنه الأداة ما راح تكون مفيدة إذا ما تكدر تخصّصها من تكون جاهز.
